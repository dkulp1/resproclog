One-time setup (5 min)

  1. Open Google Sheets and create a new sheet (or open a copy of your existing log).
  2. Go to Extensions → Apps Script.
  3. Delete any starter code and paste in the script below.
  4. Click Deploy → New deployment, choose type Web app.
  5. Set "Execute as" to Me and "Who has access" to Anyone, then Deploy.
  6. Authorize when prompted, then copy the web app URL it gives you.
  7. Paste that URL above and tap Save connection.
